# Voice

The app is for one person running their own job search. It talks to them as
"you", in plain short sentences, and says what happened and what to do next.

## Glossary

Use one word per idea, everywhere.

| Use | Not |
| --- | --- |
| resume | CV |
| search (Search now, Last searched, the next search) | fetch, scrape, run |
| Apply yourself (you apply on the company's site) | Needs manual apply |
| Dismiss / Dismissed (you passed on it) | Rejected |
| Rejected (the company turned you down) | Dismissed |
| Not eligible (the app hid it, with the reason) | Filtered, blocked |

## Rules

- A button names what it does: "Email application", "Mark applied",
  "Save version". Not "Submit" or "OK".
- An error says what failed and what to do: "The draft failed. Try again."
  Not "Something went wrong".
- An empty state says what will appear and gives the one action that fills it.
- No dashes or colons to join two thoughts. Write two sentences.
- No hype words (seamless, powerful, supercharge), no exclamation marks and
  no emoji.

## Examples

| Before | After |
| --- | --- |
| Approve (on an email job) | Email application |
| Guess - verify before sending. | This address is a guess. Check it before you send. |
| Nothing here yet. The next daily run will add new matches. | Nothing here yet. The next search adds new matches. |
